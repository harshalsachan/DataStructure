# DataStructure

## 🌳 BST Visualizer

An interactive, fully-animated **Binary Search Tree Visualizer** built with vanilla HTML, CSS, and JavaScript (Canvas API).

Open **[BST-Visualizer/index.html](BST-Visualizer/index.html)** in any modern browser — no build step required.

### Features

| Category | Details |
|---|---|
| **Animations** | Smooth step-by-step insert / delete / search; spring-physics node layout transitions; glow & pulse effects; color-coded node states |
| **Core Operations** | Insert, Delete (all 3 cases), Search — each fully animated |
| **Traversals** | In-order · Pre-order · Post-order · Level-order with scrolling value banner |
| **Interactivity** | Speed slider (1×–10×) · Pause / Resume · Step-through mode · Replay last operation |
| **Metrics** | Real-time height, node count, min, max, balance factor, comparison count, balanced/unbalanced badge |
| **Extra** | Export tree as JSON · Export canvas as PNG · Dark / Light theme toggle · Responsive layout |

### Color Legend

| Color | Meaning |
|---|---|
| 🟢 Green | Newly inserted node / Found |
| 🟡 Amber | Currently comparing |
| 🔴 Red | Being deleted |
| 🟣 Purple | Traversal visit |
| 🟠 Orange | Search path |
